## Подготовка и запуск

Нужен Python 3.10 или новее. Внешних библиотек для приложения нет.
Сборка не требуется. В PowerShell из корня проекта:

```powershell
py -3 -m venv .venv
.\run.bat
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`run.bat` выбирает `.venv`, затем `py -3`, затем `python`, передаёт все
аргументы и возвращает код завершения программы. Рабочий каталог — корень
проекта; относительные пути параметров отсчитываются от него.
При прямом запуске `python -m src.shell_emulator.main` пути считаются от cwd.

## Структура и проверка качества

`src/shell_emulator/` — приложение; `tests/` — тесты текущего этапа;
`run.bat` — запуск; `.gitignore` — исключение служебных файлов.
Файл `tests/test_quality.py` проверяет структуру, длины, аргументы,
docstrings, snake_case и числовые литералы в сравнениях.
Внешняя проверка при разработке: flake8 с pep8-naming и сложностью ≤10,
radon. Ограничения: файл ≤1000 строк, Python-строка ≤80 символов,
функция ≤40 строк, аргументы ≤7. Данные VFS не распаковываются на диск.

## Интерфейс и команды

Консольный REPL, приглашение `username@hostname:~$` использует реальные
данные ОС. Парсер поддерживает одинарные/двойные кавычки и экранирование
через shlex. Пустой ввод пропускается; ошибки не завершают REPL.
`exit` без аргументов, EOF или Ctrl+C завершают сеанс.

`ls` и `cd` — заглушки: выводят своё имя и переданные аргументы.

## Интерактивная демонстрация

```text
ls
cd "my folder"
unknown
cd "unfinished
exit
```

Пример показывает обычный ввод, аргумент с пробелом, неизвестную команду
и ошибку кавычек. Для реальной VFS отсутствующий каталог даёт ошибку.

## Функции исходного кода

### `main.py`

- `create_prompt` — Возвращает приглашение с реальными пользователем и хостом.
- `execute_stub` — Показывает имя и аргументы команды-заглушки.
- `execute_command` — Выполняет команду текущего этапа.
- `execute_line` — Разбирает строку и возвращает результат выполнения.
- `run_interactive_mode` — Читает команды до exit, EOF или прерывания пользователем.
- `main` — Запускает интерактивный эмулятор.

### `parser.py`

- `parse_command` — Разбирает строку команды на имя команды и аргументы.
