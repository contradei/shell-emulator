# Shell Emulator

Эмулятор командной строки UNIX-подобной системы.

Практическая работа по конфигурационному управлению.

Автор: Дериглазов Роман

Вариант: 9

## Этап 1

Реализован интерактивный режим командной строки.

Поддерживаемые команды:

- `ls` — заглушка команды просмотра файлов;
- `cd` — заглушка команды перехода между каталогами;
- `exit` — завершение работы эмулятора.

Парсер поддерживает аргументы, заключённые в кавычки.

Пример:

```text
ls "my folder"
Команда: ls
Аргументы: ['my folder']
```

## Этап 2

Добавлены параметры командной строки:

- `--vfs` — путь к файлу виртуальной файловой системы;
- `--script` — путь к startup-скрипту.

Startup-скрипт содержит последовательность команд, которые выполняются при запуске эмулятора.

При возникновении ошибки выполнение startup-скрипта прекращается.

Пример запуска:

```text
python -m src.shell_emulator.main --script startup.txt
```

## Этап 3

Реализована виртуальная файловая система, которая загружается из XML-файла и хранится в оперативной памяти.

Поддерживаются:

- каталоги;
- файлы;
- вложенные каталоги;
- переход между каталогами;
- просмотр содержимого текущего каталога;
- данные файлов в формате Base64.

Поддерживаемые команды:

- `ls` — вывод содержимого текущего каталога;
- `cd` — переход в каталог;
- `exit` — завершение работы.

Для перехода в родительский каталог используется:

```text
cd ..
```

VFS загружается с помощью параметра `--vfs`.

Пример:

```text
python -m src.shell_emulator.main --vfs vfs/several_files.xml
```

Startup-скрипт можно запустить вместе с VFS:

```text
python -m src.shell_emulator.main --vfs vfs/several_files.xml --script startup.txt
```

### Варианты VFS

В каталоге `vfs` находятся тестовые XML-файлы:

- `minimal.xml` — минимальная виртуальная файловая система;
- `several_files.xml` — VFS с несколькими каталогами и файлами;
- `nested.xml` — VFS с несколькими уровнями вложенности;
- `invalid.xml` — файл с некорректным XML;
- `base64.xml` — VFS с файлом, содержащим данные в Base64;
- `invalid_base64.xml` — VFS с некорректными данными Base64.

### Скрипты проверки

В каталоге `scripts` находятся скрипты для запуска различных вариантов VFS:

- `test_minimal.bat`;
- `test_several_files.bat`;
- `test_nested.bat`.

Пример запуска:

```text
scripts\test_nested.bat
```

### Обработка ошибок

При отсутствии VFS-файла выводится сообщение об ошибке.

При некорректном XML выводится сообщение:

```text
Ошибка загрузки VFS: Некорректный формат VFS-файла
```

При некорректных данных Base64 выводится сообщение:

```text
Ошибка загрузки VFS: Некорректные данные Base64
```

При неизвестной команде выводится сообщение об ошибке, после чего startup-скрипт прекращает выполнение.
